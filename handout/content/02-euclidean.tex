\subsection{Tessellation with Möbius
Triangles}\label{tessellation-with-muxf6bius-triangles}

\begin{itemize}
\tightlist
\item[$\square$]
  requires discussion about angle sum
\end{itemize}

A triangle tiling is a tiling made from Schwarz triangles.

A \emph{Möbius triangle} is a triangle defined by the three tuple \((p q r)\) with \(p, q, r \in \mathbb{Z}^+\), which represent it's internal angles. The
angle at each vertex are given by

\[
\begin{matrix}
\alpha = \frac{\pi}{p} & \beta = \frac{\pi}{q} & \gamma = \frac{\pi}{r}
\end{matrix}
\]

Not all choices for \((p q r)\) yield a valid triangle. Must must ensure
that the angles form a valid internal angle sum. For a triangle in the
Euclidean Plane the angles must add up to \(\pi\), hence (p, q, r)
define a Euclidean triangle exactly when

\[
\alpha + \beta + \gamma = \pi \Rightarrow
\frac{1}{p} + \frac{1}{r} + \frac{1}{q} = 1
\]

We can tessellate a surface by continuously reflecting a Möbius triangle
along it's edges.

Note that all permutations of \(p, q, r\) will produce a similar
triangle and henceforth congruent tilings,
\((p, q, r) \cong (q, r, p) \cong (r, p, q)\), etc.

\subsubsection{Proof of Existence}\label{proof-of-existence}

Let \(p, q, r \in \mathbb{Z}^+\) be the coefficients of a möbius
triangle. We shall proof for which choices of \(p, q, r\) there exists a
valid \textbf{Eulcidean} tiling. In order to formulate an exhaustive
proof, we order the coefficients such that \(p \le q \le r\). This way
we will cover all unique tilings without repetition.

Our strategy in this proof is to consequtively limit the number of
choices for each coefficient in order put a bound on our solution space, which we can then check case by case.

In Euclidean geomerty the angle sum of a triangle is \(\pi\), therefore

\begin{equation}
\frac{1}{p} + \frac{1}{q} + \frac{1}{r} = 1
\label{eq:pqr-sum-euc}
\end{equation}.

We want \(p\) to assume the its lowest possible values, i.e.~to
represent the largest possible angle in our triangle. As a lower bound
we have \(2 \le p\), since if \(p\) was one, the other coefficients
would have to be 0. Our upper bound is reached when \(p = q = r \Rightarrow \frac{3}{p} = 1\),
therefore if we apply (\ref{eq:pqr-sum-euc}) we get \(p \le 3\). We have now determined the possible values for \(p \in \{ 2, 3 \}\).

% If p where to be larger than 3 either q or r would have to be smaller than r, which would break our ordering.

We now have a value for \(p\) and can continue limiting the choices for \(q\) in the same way. Our lower bound is given by \(p \le q\). 
We can again determine an upper bound by setting \(q = r\) we get \(\frac{1}{p} + \frac{2}{q} = 1\)

% q cannot be smaller than p, since that would break our ordering. q cannot be larger than the expressed value since otherwise r would have to be smaller.

\[
% \frac{2}{q} = 1 - \frac{1}{p} \\ \Leftrightarrow
% \frac{2}{q} = \frac{p-1}{p} \\ \Leftrightarrow
q = \frac{2p}{p-1}
\]

We could continue this scheme further for \(r\). However in the Euclidean case we may directly solve for \(r\) using the equation (\ref{eq:pqr-sum-euc}). Therefore we get

% Upper bound for r
\[
\frac{1}{r} \le 1 - \frac{1}{p} - \frac{1}{q} \\ \Leftrightarrow
\frac{1}{r} \le \frac{pq - p - q}{pq} \\ \Leftrightarrow
r \le \frac{pq}{pq-p-q} \\
\]

\pagebreak

We analyze the cases for $r$ bounded by $2 \le r \le 3$.
\begin{itemize}
\item[If \(r = 2\)] then \(q\) is bounded by \(2 \le q \le 4\).
  % q <= (2*2)(2-1) = 4
  \begin{itemize}
    \item[If \(q = 2\)] then \(r = 0\), which is not a result, since $0 \not\in \mathbb{Z}^+$.
    \item[If \(q = 3\)] then \(r = 6\), which gives us a valid triangle \((2~3~6)\). \checkmark
    \item[If \(q = 4\)] then \(r = 4\), which gives us a valid triangle \((2~4~4)\). \checkmark
  \end{itemize}
\item[If \(r = 3\)] then \(q\) is bounded by \(3 \le q \le 3\).
  \begin{itemize}
    \item[If \(q = 3\)] then \(r = 3\), which gives us a valid triangle \((3~3~3)\). \checkmark
  \end{itemize}
\end{itemize}


\subsection{Euler Characteristic}\label{euler-characteristic}

The euler characteristic of a cell division is given by {[}Weeks,
pp.171{]} Where \(V\) is the number of vertices, \(E\) the number of
edges and \(F\) the number of faces

\(\chi = V - E + F\)

For polyhedra \(\chi=2\) since they can be embedded on the sphere
\(\mathbb{S}^2\) {[}Coxeter, pp.~10{]}

The gauss-bonnet formula gives the area of different surfaces

\(A_\text{sphere} = 2\pi\chi\)
